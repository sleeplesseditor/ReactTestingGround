## Description
An app for investigating and demonstrating some of the new features in React 19.3.0. The app is live on GitHub Pages and can be viewed [here](https://sleeplesseditor.github.io/ReactTestingGround/).

## Running the App Locally
- CD into the repo folder
- Run `npm install`
- Run `npm run dev`
